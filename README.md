# SetHome Plugin 1.16.5
## About this is plugin
Feautures:
- Commands: /sethome <name>, /delhome <name>, /homes.
- A custom GUI of a homes.
- SQLite for data storage(UUID, nickname, names of homes, world and X Y Z)
- Configs: you can selecting a translation - Russian or English. But in default set up Russian language. And you can to changes a messages from configs.
- About commands: /sethome <name> - creating a home, /delhome <name> - deleting a home, /homes - opening a custom GUI of a homes with a information(name, world and X Y Z).

## Requirements
- A Minecraft server: download paper or spigot in 1.16.5 version.
- Java: 16 version.
